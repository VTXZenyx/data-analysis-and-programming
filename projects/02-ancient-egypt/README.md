# Ancient Egypt isotope analysis

[← All projects](../../README.md)

**Goal:** Explore how strontium isotope ratios vary across archaeological records.

![Strontium isotope comparison](preview.png)

**What I did:** Imported an Excel workbook, combined worksheets and used `dplyr` summaries and `ggplot2` comparisons to explore the measurements.

**Skills:** Excel import · joins · grouped statistics · visualisation

**Code:** [isotope_analysis.R](isotope_analysis.R) · [Original Assignment 2](../../coursework/assignment2.Rmd)

To rerun, put `EgyptData.xlsx` in this folder and run the script in RStudio. This descriptive analysis does not prove a historical migration hypothesis.
