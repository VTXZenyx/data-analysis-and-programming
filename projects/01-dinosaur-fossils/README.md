# Dinosaur fossil mapping

[← All projects](../../README.md)

**Goal:** Visualise where dinosaur fossils were recorded and compare categories.

![Dinosaur fossil locations](preview.png)

**What I did:** Imported a fossil CSV, filtered invalid coordinates and unrecognised dinosaur types, then mapped records in R using `ggplot2` and `maps`.

**Skills:** R data cleaning · factor levels · spatial visualisation

**Code:** [dinosaur_analysis.R](dinosaur_analysis.R) · [Original Assignment 1](../../coursework/assignment1.Rmd)

To rerun, put `dinosaurs.csv` in this folder and run the script from this folder in RStudio. The original dataset is not published here.
