# Probability and simulation models

[← All projects](../../README.md)

**Goal:** Explore real questions through random simulation in R.

![Simulation output](preview.png)

**What I did:**

1. Simulated genetic inheritance over 21 generations, using 50 individuals and 100 markers.
2. Simulated customer arrivals over 1,000 shop days using exponential waiting times.
3. Generated 10,000 synthetic categorical observations from a three-group mixture model.

**Skills:** Random sampling · custom functions · loops · matrices and arrays · Monte Carlo simulation

**Code:** [simulations.R](simulations.R) · [Original Assignment 3](../../coursework/assignment3.Rmd)
